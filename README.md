# java-introducao
Resolução da Lista de Exercícios TP01 utilizando Java, com foco em conceitos básicos de programação, entrada de dados e operações matemáticas.

TP01-Lista de Exercícios Java
📌 Sobre o projeto

Este repositório contém a resolução da Lista de Exercícios TP01, desenvolvida utilizando a linguagem Java.

A atividade tem como objetivo praticar os fundamentos da programação por meio de problemas simples envolvendo entrada de dados, processamento de informações e operações matemáticas.

📚 Exercícios
01 — Desconto de produto

Programa que recebe o nome e o valor de um produto e calcula seu novo valor após a aplicação de um desconto de 9%.

02 — Salários mínimos

Programa que recebe o valor do salário mínimo e o salário de uma pessoa e calcula quantos salários mínimos ela recebe.

03 — Média de valores

Programa que recebe dois valores e calcula a média entre eles, utilizando o tipo float.

04 — Conversão de temperatura

Programa que converte uma temperatura em Celsius para Fahrenheit, utilizando a fórmula:

F = (9 × C + 160) / 5

05 — Volume de uma lata

Programa que calcula o volume de uma lata de óleo a partir do seu raio e altura, utilizando a fórmula:

V = 3.14159 × R² × H

🎯 Objetivos

Através dos exercícios, são trabalhados conceitos fundamentais como:

Estrutura básica de programas em Java.

▶️ Execução

Para executar os exercícios, é necessário ter o JDK instalado.

Cada arquivo pode ser compilado e executado individualmente pelo terminal:

javac Exercicio01.java
java Exercicio01

O mesmo procedimento pode ser realizado para os demais exercícios, alterando o nome do arquivo.
